# Contributing to Ikshvaku General Awareness Question Bank (SSC CGL & CHSL PYQ Standard)

Official repository for **Ikshvaku Aptitude Arena** by **Ikshvaku Vidya Academy** ("Practice. Think. Compete.").

All questions conform to `schema/question-schema.json`.
Format: `GA-[TOPIC_CODE]-[6 DIGIT NUMBER]`.
Tagged with SSC exam metadata (e.g., `SSC-CGL-2023`, `SSC-CHSL-2022`).
